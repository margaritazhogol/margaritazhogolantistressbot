**📖 О проекте**

Telegram-бот проводит короткий опрос из 15 вопросов, помогающий человеку обратить внимание на своё текущее эмоциональное состояние, и по итогам набранных баллов даёт персональные рекомендации.      

Проект — переработанная версия учебного психологического опросника (изначально собранного в no-code конструкторе) в виде полноценного Python-бэкенда с хранением результатов в базе данных.      

⚠️ Бот не является медицинским диагностическим инструментом и не заменяет консультацию специалиста — об этом честно предупреждается в самом боте.     

**✨ Возможности**     
📋 Последовательный опрос из 15 вопросов с 5 вариантами ответа (Да / Скорее да / Сомневаюсь / Скорее нет / Нет), каждый вариант имеет свой вес в баллах    
📊 Автоматический подсчёт итогового балла (0–60) и подбор одного из трёх результатов с персональными рекомендациями     
🆘 Постоянная кнопка экстренной помощи — работает в любой момент диалога и сразу показывает телефон доверия, не дожидаясь окончания теста     
🔒 Дисклеймер о конфиденциальности и характере бота в самом начале     
💾 Сохранение результатов прохождения в SQLite для последующей анализа (без хранения текстов ответов — только итоговый балл)      

**🛠️ Технологии**
